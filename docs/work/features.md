# Նոր հնարավորություններ

## Հիմա
- Սաղմոսի համարի պատուհան (Պատճենել / Կիսվել / Պահել / ▶ Լսել այստեղից) և համարի էջ `/saghmosner/22/3` — `feat/verse-popup`, staging-ում ստուգման։

## Հերթ
1. Համարի վրա սեղմելիս պատուհան, ինչպես bible.com-ում՝ Պատճենել / Կիսվել / Պահել / ▶ Լսել այստեղից։ «Կիսվել»-ը բացում է միայն այդ համարի էջը (`/saghmosner/22/3`)՝ «Կարդալ ամբողջ սաղմոսը» հղումով։
2. Ամեն նյութի տակ աղբյուրի/հեղինակի տող։
3. «Հայտնել սխալի մասին» կոճակ նյութի էջում։
4. Սաղմոսների ցանկում «Շուտով» նշում դեռ չավելացվածների համար և համարակալման բացատրություն։
5. Ընթերցանության առաջընթաց ըստ բաժնի։
6. Բովանդակություն՝ 7 խորհուրդների PDF → հոգևորականների ստուգում → «Եկեղեցական կյանք» թեմա Telegram-ում → ծեսեր և արարողություններ։
7. Ավելի ուշ՝ աուդիոյի օպտիմալացում, տառատեսակներ, դիզայն և պատկերներ։

# Ավտոմատ համաժամեցում VPS-ում

Այս սերվերը միայն մի գործ ունի. լսել Telegram խումբը և նոր, խմբագրված կամ ջնջված
գրառումները մի քանի վայրկյանում հասցնել Cloudflare (D1 + R2)։ Կայքն ինքը
Cloudflare-ում է, ուստի սերվերի կարճ անջատումը կայքին չի խանգարում. նյութերը
կթարմանան, երբ այն նորից աշխատի։

## Ինչպես է աշխատում

1. Telegram-ում նոր գրառում ես անում։
2. Սերվերը մոտ 8 վայրկյան սպասում է (որ նկարների album-ը մեկ անգամ մշակվի),
   ստուգում է հեղինակին և գրում D1/R2։
3. Կայքը նոր նյութը ցույց է տալիս առավելագույնը մեկ րոպեում։
4. Ամեն 6 ժամը մեկ սերվերը ամբողջական ստուգում է անում. եթե ինչ-որ բան բաց է
   թողնվել (օրինակ՝ սերվերը անջատված է եղել), այն կլրացվի։

Հեղինակի կանոնը. կայք են գնում խմբի ադմինների, ադմինի էջում թույլատրված մարդկանց
և անանուն ադմինների («խմբի անունից») գրառումները։ Մնացածները թաքցվում են ու
երևում են ադմինի էջի «Թաքցված հեղինակներ» բաժնում։

## Քայլեր (քո կողմից՝ միայն 1-ին և 2-րդը)

1. **Սերվեր գնել։** Hetzner Cloud → CX22 (2 vCPU, 4 GB, ~4.5 €/ամիս), Ubuntu 24.04,
   տեղը՝ Germany կամ Finland։ «SSH keys» բաժնում ավելացրու քո Mac-ի բանալին
   (`cat ~/.ssh/id_ed25519.pub`)։ Ինձ ուղարկիր սերվերի IP-ն։
2. **Cloudflare API token։** dash.cloudflare.com → My Profile → API Tokens → Create
   Token → Custom token՝ `Account · D1 · Edit` և `Account · Workers R2 Storage · Edit`,
   միայն քո account-ի համար։ Token-ը ինձ չուղարկես. երբ սերվերը պատրաստ լինի,
   ես կբացեմ ֆայլը, ու դու ինքդ կտեղադրես token-ը։
3. Մնացածն անում եմ ես քո Mac-ից SSH-ով. Docker-ի տեղադրում, կոդի պատճենում,
   `/opt/library/cloud-sync.env` ֆայլի պատրաստում, գործարկում և ստուգում։

## Ստուգում և կառավարում

```bash
docker compose -f deployment/docker-compose.yml logs -f --tail 50
docker compose -f deployment/docker-compose.yml restart
```

Log-ում պետք է երևա `watching`, իսկ ամեն գրառումից հետո՝ `changes-done`։ Ադմինի էջի
«Համաժամեցում» բաժինը ցույց է տալիս վերջին համաժամեցման ժամն ու արդյունքը։

## Անվտանգություն

- `cloud-sync.env`-ը միայն root-ին հասանելի է (`chmod 600`), git-ում չկա։
- Telegram session-ը նույն user session-ն է, ինչ Mac-ում։ Կասկածի դեպքում Telegram →
  Settings → Devices-ում փակիր այն ու `pnpm telegram:authorize`-ով ստեղծիր նորը։
- Սերվերը ոչ մի port չի բացում. միայն դուրս է գնում Telegram և Cloudflare։

# apostolic.am • ուսուցողական վիդեոների ընդհանուր ձևանմուշ (v2)

Այս ոճն ընտրել է կայքի սեփականատերը՝ 2026-11-05-ի դիտարկումներից հետո։ **Հաջորդ հոլովակներում պահել առանց նորից հարցնելու**, եթե օգտատերը հակառակը չի խնդրում։

## Անփոփոխ ոճ

- 9:16 · 1080×1920 · H.264 MP4 · 24 FPS · առանց ձայնի։ Կարճ ու հասկանալի՝ սովորաբար 20–30 վայրկյան։
- Կենտրոնում մեծ հեռախոսի էկրան՝ **կայքի իրական** բջջային UI տեսագրությամբ։
- Դրսի ֆոնը՝ կայքի բաց թեմային մոտ՝ ivory/մագաղաթի նուրբ, բնական հյուսվածք։
- **Մի՛ ավելացրու** վերևի «Հոգևոր ժառանգություն» պիտակը, կիսակլոր աղեղներ, զարդագծեր, գունավոր քարտեր և այլ դեկորացիաներ։ Օգտագործիր կայքի ինքնության պարզությունը։
- Վերևում կարող է լինել միայն կարճ ուսուցողական վերնագիր, ընթացիկ քայլի կարճ հայերեն հրահանգ ու առավելագույնը մեկ բացատրություն։
- Սեղմման արձագանքը պետք է երևա **սեղմման պահին**, ոչ մի ուշացող կամ կրկնակի երկրորդ ալիք։ Եթե արձագանքն արդեն առկա է սկզբնական տեսագրությունում, լրացուցիչ օղակ մի՛ ավելացրու։
- Ներքևում՝ մշտական, հստակ, հանգիստ `apostolic.am` հասցեն։ Latin գրության համար Latin glyph ունեցող տառատեսակ ընտրել։
- Հայերեն՝ կարճ, անսխալ, ընթեռնելի. նախընտրելի Noto Sans Armenian/Noto Serif Armenian։
- Վերջում՝ կարճ արդյունք, առանց պարտադիր հավելյալ գրաֆիկական քարտի։

## Ուղեցույցների խմբավորում

Հարակից ֆունկցիաները խմբավորել, որպեսզի շատ մանր վիդեոներ չլինեն.

- **Տառերի կարգավորումներ**՝ տառատեսակ, ընդհանուր տառաչափ, վերնագրերի չափ (Փոքր, Միջին, Մեծ)՝ **մեկ հոլովակ**։
- **Թեմայի փոփոխություն**՝ առանձին հոլովակ։
- Այլ հնարավորությունները՝ խմբավորել ըստ օգտատիրոջ մեկ հասկանալի նպատակի։

## Պատրաստման ընթացք

1. Ստուգել կայքի ընթացիկ public UI-ն և անհրաժեշտության դեպքում `app/components/` կոդը։
2. Նկարահանել իրական գործողությունները բջջային viewport-ով՝ Playwright կամ browser recorder։
3. Պահել կադրերն ու click/tap timestamp-երը։
4. Օգտագործել նույն հիմնական ֆոնը, տեսողական շեշտերը, հեռախոսի դիրքն ու footer-ը։ Փոխել միայն սցենարը, իրական տեսագրությունն ու տեքստերը։
5. Վիդեոն ամբողջությամբ ստուգել՝ ոչ մի կրկնակի ալիք, սխալ սեղմում, կիսատ վերնագիր, երկրորդ `apostolic.am` կամ անտեղի դեկորացիա։
6. Արտահանել ամբողջական MP4 + պահպանել editable project/template։

### 2026-11-05-ի v2 օրինակ

«Տառատեսակ և տառաչափ»՝ մոտ 27 վրկ, 1080×1920, 24 FPS, առանց audio stream-ի։
Նախնական աղբյուրը օգտատիրոջ իրական էկրանի տեսագրությունն է։ «Վերնագրերի չափ» հատվածը աղբյուրում բացակայում էր և օրինակում ցուցադրված է `app/components/settings-panel.tsx` կառուցվածքին համապատասխան **վերակազմված** տեսքով։ Այն չի ներկայացվում որպես նոր իրական browser recording։ Նոր վիդեոների համար ձգտել ստանալ ամբողջական իրական capture։

Editable Python renderer, screenshot frames և MP4-ն օգտատիրոջը տրամադրված են ChatGPT խոսակցության v2 ZIP փաթեթով։ Քանի որ GitHub connector-ը այստեղ UTF-8 տեքստ է գրում, երկձևման համար կցված ZIP-ի բինար աղբյուրները չեն ավելացվել repository-ում։

# Որոնիչների տեսանելիություն — 2026-11-12

Հիմք՝ վերջին production `5a9bc36` (PR #168 և #169՝ դիզայնի, սահունության և որոնման փոփոխություններով)։ Staging-ի ֆայլերը համեմատման պահին նույնն էին։ Նախորդ չաթի չպահված հետազոտական ֆայլերը չեն ներառվել այս ճյուղում։

## Հաստատված վիճակ

Production sitemap-ի բոլոր 231 հասցեները հերթով ստուգվել են երկու զուգահեռ հարցմամբ։ Բոլորը վերադարձրել են 200, ունեցել են իրենց հասցեին համապատասխան canonical, չեն ունեցել noindex կամ կրկնվող վերնագիր։ Հիմնական բաժինների ու ստուգված նյութերի բովանդակությունը կա սերվերի HTML-ում։ `robots.txt`-ը Google Search-ի ընդհանուր արգելք չունի։ Հին `/saghmosner/47` և `/post/407` հասցեները ճիշտ 301-ով գնում են `/psalms/47`։

Սա չի ապացուցում, որ Google-ն արդեն ինդեքսավորել է էջերը։ Search Console-ի 522/427/40 խմբերի հասցեների արտահանումը դեռ չի տրամադրվել․ դրանց բոլոր պատճառները հայտնի չեն։ Ընդհանուր ցանկում redirect/noindex/robots բացառումները միշտ սխալ չեն։

## Կատարված փոփոխություններ

- `seoMeta()`-ում հիմնական որոնիչային հասցեն առանձնացված է `og:url`-ից՝ `canonicalPath` ընտրանքով։ Canonical-ը միշտ production դոմենով է, իսկ staging-ի կիսվելու հասցեն մնում է staging-ում։ Staging-ի noindex վերնագիրը պահպանված է։
- Համարի էջը (`/psalms/47/3`) canonical-ով ցույց է տալիս ամբողջ սաղմոսը (`/psalms/47`)։ Չկա վերահղում կամ նոր noindex։ Ստացողի UI-ը, համարը, հարևան համարները, ամբողջ սաղմոսի հղումը և նկարի նախադիտումը պահպանված են։
- Սաղմոսի որոնման վերնագիրը սկսվում է համարով՝ օրինակ «Սաղմոս 47․ …»։ Նկարագրական անվանումը հնարավորության սահմաններում պահվում է, և երկար վերնագրում համարը չի կտրվում։ Ընթերցվող տեքստը չի խմբագրվել։
- `scripts/seo-audit.mjs`՝ sitemap-ի բոլոր հասցեների HTTP, canonical, noindex, title, description և H1 ստուգում՝ երկու զուգահեռ հարցմամբ։ Գործարկում՝ `node scripts/seo-audit.mjs https://apostolic.am`։ Սա ձեռքով գործարկվող գործիք է․ մշտական հարցումներ կամ նոր ծառայություն չի ավելացնում։

Sitemap-ից հանվել են բաժնի առաջին տեքստային ներածությունները՝ կայքի որոնման ինդեքսի գործող կանոնով։ Նախնական 231 հասցեից հենց այդ 4 հասցեներին ներքին հղում չէր տանում․ մյուս 227-ը հասանելի էին գլխավորից HTML հղումներով։ Ներածությունների տեքստն ու հին էջերը պահպանվում են։

Robots-ի անձնական բաժինների սահմանափակումները, նվագարկիչները, որոնումը, նշումները, օգտատերերի տվյալներն ու չատը չեն փոխվել։ Բովանդակություն չունեցող սրբավայրերի նպատակային noindex-ը չի հանվել։

## Search Console-ում նվազագույն հաջորդ քայլը

Սկզբում միայն `https://apostolic.am/` → URL inspection → Test live URL։ Եթե Google-ի կենդանի ստուգումը թույլ է տալիս ինդեքսավորում, սեղմել Request indexing։ Եթե չի թույլ տալիս, կարդալ կոնկրետ պատճառը, ոչ թե կրկնել ուղարկումը։

Արդեն Success ունեցող `https://apostolic.am/sitemap.xml`-ը ջնջելու/նորից ավելացնելու կարիք չկա։ Canonical-ի փոփոխությունից հետո համարների էջերի համար «այլընտրանքային էջ՝ ճիշտ canonical-ով» վիճակը նորմալ արդյունք է։ Request indexing-ը առաջնահերթ ամբողջ սաղմոսի/բաժնի համար է, ոչ ամեն համարի։

Հաջորդ որոշումը՝ 522 «Crawled», 427 «Discovered» և 40 «Duplicate» խմբերի հասցեները համեմատել գործող 231 հիմնական էջերի հետ։ Եթե կարևոր հիմնական էջերը շարունակում են բացակայել, ուսումնասիրել հենց դրանց վերջին crawl-ը, Google-selected canonical-ը, Crawl stats-ը, Manual actions/Security issues-ը և բովանդակության տարբերակիչ արժեքը։ Այս տվյալները հանրային կայքից չեն երևում։

Անմիջապես կամ որոշակի ժամկետում Google-ում հայտնվելու խոստում չկա․ canonical-ը հուշում է, իսկ ինդեքսավորման վերջնական ընտրությունը Google-ինն է։

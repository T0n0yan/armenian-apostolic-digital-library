# Դիզայնի կանոններ

Ամեն նոր էջ, կոճակ կամ քարտ ավելացնելիս՝ միայն այս կանոններով։ Թոքենները՝ `app/app.css`
(`@theme static`, `--lg-*`, `--field-border`), պատրաստ class-երը՝ `app/components/ui-styles.ts`։

> **Տիրոջ որոշում (2026-11-25).** Դիզայնի ամեն փոփոխություն, նույնիսկ ամենաչնչինը, նախ համաձայնեցնել տիրոջ հետ, հետո անել։

## 1. Կլորացում (border-radius)

Միայն 5 չափ և `rounded-full`։ `rounded-[13px]`-ի նման կամայական թվեր չգրել։

| Class | Չափ | Որտեղ |
| --- | --- | --- |
| `rounded-chip` | 8px | փոքր նշաններ, պիտակներ, badge |
| `rounded-control` | 12px | պատկերակով փոքր կոճակներ (36px), փոքր դաշտեր, մենյուի սալիկներ (տիրոջ որոշում, 2026-11-25) |
| `rounded-button` | 16px | կոճակներ, input-ներ, որոնման դաշտ |
| `rounded-card` | 22px | քարտեր (`paper-card`), ֆիլտրերի խմբեր, քարտեզ |
| `rounded-panel` | 28px | վահանակներ (`paper-panel`), մենյու, ներքևի պատուհաններ |
| `rounded-full` | — | կլոր կոճակներ, pill-եր, avatar |

CSS-ում՝ `var(--radius-card)` և այլն։ Միայն 3–4px (գծեր, progress) կարող են մնալ թվով։

**Ներդրման կանոն.** ներսի կլորացումը = դրսինը − padding։
Օրինակ՝ քարտ 22 + `p-1.5` (6px) → ներսի կոճակները 16 (`rounded-button`)։
Մենյու 28 + `p-3` (12px) → սալիկները 16։ Եթե թիվը չի համընկնում, փոխել padding-ը, ոչ թե շառավիղը։
Դաշտի ներսի կոճակը միշտ կլոր է (`rounded-full`), որ կանոնը չխախտվի։

## 2. Մակերեսներ (թուղթ, առանց ապակու)

Liquid glass-ը հանված է 2026-11-25 (տիրոջ որոշում). blur-ը, լույսի օղակը (դիմակով) և շերտավոր ստվերները
հեռախոսում ամեն կադր վերանկարվում էին, մենյուն ու թեմայի փոխումը կտրտվում էին, իսկ Apple-ի իսկական
ապակին կայքում ճիշտ անել հնարավոր չէ։ Հիմա ամեն ինչ «թուղթ» է՝ մինիմալ և թեթև։

- Քարտ՝ `paper-card`, վահանակ՝ `paper-panel`. կիսաթափանց թուղթ (`--card-bg`), բարակ եզր (`--card-edge`, 0.5px),
  մեկ փափուկ ստվեր (`--soft-shadow`)։ Մենյու՝ `menu-panel` (`--menu-bg`), սալիկ մենյուում՝ `menu-tile` (`--tile-bg`),
  մենյուի կոճակ՝ `paper-fab` (`--fab-bg`)։
- **Ամեն լողացող տարր** (ներքևի պատուհան, toast, dropdown, բառարանի/նշումների փոքր պատուհան, հիշեցում)՝ `paper-sheet`
  (անթափանց `--sheet-bg`), նրա սլաքը՝ `sheet-arrow`։ `bg-[var(--page-bg)]` լողացող տարրին չդնել։
- Ներքևից բարձրացող պատուհան (drawer)՝ միշտ `BottomSheet` (`app/components/bottom-sheet.tsx`), ոչ թե նոր գրադարան։
  `swipeToClose`-ով վերևում բռնակ է, ներքև քաշելով փակվում է (օր.՝ հիշեցումները)։
- Ընտրված հատված (segment, ներդիր)՝ `chip-on`. սահող ներդիրի ֆոն՝ `tab-glider` (տես «Իմ անկյունը»)։
  Ներդիր փոխելիս էջի տվյալները նորից չբեռնել (`shouldRevalidate`)։
- Եզրի գույնը՝ `border-edge` (`--edge`), կիսաթափանց ֆոնը՝ `bg-surface` / `bg-surface-strong`։
- **ՉԴՆԵԼ** `backdrop-filter` (blur), SVG ֆիլտրեր (`feDisplacementMap`), `mask`-ով եզրեր, 3-ից ավելի շերտով ստվեր,
  `background-position`/`width`/`top` անիմացիա։ Փորձվել են (Glisse, կենդանի բեկում, liquid glass) և հանվել։
- Թեման փոխելը՝ միայն `applyThemePreference`-ով (`theme.ts`). գույները փոխվում են միանգամից, առանց View Transition-ի։
  Կոճակների գույնի անցումները այդ պահին ավարտվում են (`finishColorTransitions`), շարժումը (`tab-glider`) մնում է։
- Մենյուում պատկերակների անիմացիաները (`.ti`) անջատված են։
- Անվերջ (`infinite`) անիմացիա չդնել. կոճակի ծաղկեպսակը պտտվում է միայն մենյուն բացելիս/փակելիս (0,7 վրկ)։
  Առաջ անընդհատ էր պտտվում, ու հեռախոսը ամեն էջում վայրկյանում 60 անգամ նկարում էր էկրանը (2026-11-25)։
- Մուտքի անիմացիաները՝ `backwards`, ոչ `both` (ավարտից հետո քարտը չպետք է մնա առանձին GPU շերտ)։
- Կարգավորման բաժինը ընտրությունից չպետք է բարձրությունը փոխի (թեման փոխելիս վահանակը ցատկում էր). տարբեր
  բացատրությունները դնել նույն տեղում (`[grid-area:1/1]` + `invisible`), ինչպես «Կայքի լուսավորություն»-ում։

## 3. Դաշտեր և որոնում

- **Էջերի որոնումը՝ միայն անկյունի կոճակից** (`ExpandingSearch`, `app/components/page-layout.tsx`).
  կլոր կոճակը սահուն երկարում է և դառնում pill դաշտ (`header-search`), X-ով կամ Esc-ով՝ հետ։
  Վերնագրի տակ առանձին որոնման դաշտ չդնել։ Բացառություն՝ գլխավոր էջը (այնտեղ մեծ դաշտ է)։
  `PageHeader`-ին՝ `search={{ open, onOpen, field }}` էջի սեփական որոնման համար, առանց դրա՝ «Փնտրել այս էջում»։

- Որոնման դաշտ՝ `search-field` (բոլոր էջերում նույնը)։ Ձախում՝ պատկերակ, աջում՝ ոսկեգույն
  կլոր `search-go` կոճակ, որը երևում է միայն տեքստ գրելուց հետո։ Input-ին՝ `enterKeyHint="search"`։
- Մնացած դաշտերը՝ `fieldControl`։ Եզրը միշտ `--field-border` է (կոնտրաստը
  ֆոնի նկատմամբ ≥ 3:1, WCAG 1.4.11)։ Մութ թեմայում դաշտը ֆոնից **բաց** է, ոչ թե մութ։

## 4. Կոճակների խմբեր

- Ընտրության խումբ (segmented)՝ `paper-card p-1.5` + ներսում `rounded-button` կոճակներ.
  ընտրվածը՝ `bg-[rgb(217_181_111/18%)]` և ոսկեգույն ներքին եզր։
- «Կարդացել եմ» (`read-mark`)՝ նույն տեսքով, ինչ գործողությունների գոտին, `rounded-card`։
- Նյութի գործողություններ՝ `action-bar` (մեկ գոտի, ներսում թափանցիկ `action-tile`)։
  Հերթականություն՝ Պահել · Հիշեցնել · Կիսվել։ Telegram-ի կոճակ չդնել (կայքը առաջնային է)։
- Մենյուի սալիկներ՝ պատկերակ վերևում, անունը տակը, մեկ բառ (մինչև ~14 տառ)։

## 5. Գույն և տեքստ

- Ոսկեգույն՝ `text-gold` / `text-gold-bright` (պատկերակներ, ակտիվ վիճակ), հիմնական տեքստ՝
  `text-ink`, երկրորդական՝ `text-muted`, նշումներ՝ `text-faint` (միայն ոչ կարևոր տեքստի համար)։
- Գլխավոր գործողություն՝ ոսկեգույն գրադիենտ `linear-gradient(135deg,#e2c27e,#b07d2e)`, տեքստը `#2a1708`։
- Գլխատառերով փոքր վերնագրեր՝ `text-[11px] font-bold tracking-[1.2px] text-gold uppercase`։

## 6. Որոնում. «Գուցե նկատի ունեիք»

`shared/search-correction.ts`. լատինատառը դառնում է հայերեն, տառասխալը ուղղվում է ըստ
վերնագրերի բառերի։ Լատինատառ կամ ոչինչ չգտած որոնումը բացվում է ուղղվածով (`?asked=`՝
մարդու գրածը, «Փնտրել հենց …» հղումով, `?exact=1`)։ Մնացածում՝ «Գուցե նկատի ունեիք» և
«Նման բառեր» կոճակներ։

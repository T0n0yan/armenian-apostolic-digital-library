# Դիզայնի կանոններ

Ամեն նոր էջ, կոճակ կամ քարտ ավելացնելիս՝ միայն այս կանոններով։ Թոքենները՝ `app/app.css`
(`@theme static`, `--lg-*`, `--field-border`), պատրաստ class-երը՝ `app/components/ui-styles.ts`։

## 1. Կլորացում (border-radius)

Միայն 5 չափ և `rounded-full`։ `rounded-[13px]`-ի նման կամայական թվեր չգրել։

| Class | Չափ | Որտեղ |
| --- | --- | --- |
| `rounded-chip` | 8px | փոքր նշաններ, պիտակներ, badge |
| `rounded-control` | 12px | պատկերակով փոքր կոճակներ (36px), փոքր դաշտեր |
| `rounded-button` | 16px | կոճակներ, input-ներ, մենյուի սալիկներ, որոնման դաշտ |
| `rounded-card` | 22px | քարտեր (`frosted-card`), ֆիլտրերի խմբեր, քարտեզ |
| `rounded-panel` | 28px | վահանակներ (`frosted-panel`), մենյու, ներքևի պատուհաններ |
| `rounded-full` | — | կլոր կոճակներ, pill-եր, avatar |

CSS-ում՝ `var(--radius-card)` և այլն։ Միայն 3–4px (գծեր, progress) կարող են մնալ թվով։

**Ներդրման կանոն.** ներսի կլորացումը = դրսինը − padding։
Օրինակ՝ քարտ 22 + `p-1.5` (6px) → ներսի կոճակները 16 (`rounded-button`)։
Մենյու 28 + `p-3` (12px) → սալիկները 16։ Եթե թիվը չի համընկնում, փոխել padding-ը, ոչ թե շառավիղը։
Դաշտի ներսի կոճակը միշտ կլոր է (`rounded-full`), որ կանոնը չխախտվի։

## 2. Ապակի (liquid glass)

- Քարտեր՝ `frosted-card`, վահանակներ՝ `frosted-panel` (առանց blur-ի՝ արագության համար), մենյու՝ `menu-panel`,
  ներքևի պատուհան՝ `liquid-sheet`, սալիկ ապակու ներսում՝ `glass-tile`։
- Blur (backdrop-filter)՝ միայն վահանակներին, մենյուին, պատուհաններին։ Ցանկի քարտերին՝ ոչ
  (թույլ հեռախոսում scroll-ը դանդաղում է)։ Ապակին ապակու մեջ blur չի ստանում։
- **Ամեն լողացող տարր** (toast, պատուհան, dropdown, բառարանի/նշումների փոքր պատուհան,
  հիշեցում)՝ `liquid-sheet`, նրա սլաքը՝ `glass-arrow`։ `bg-[var(--page-bg)]` լողացող տարրին չդնել։
- Ընտրված հատված (segment, ներդիր)՝ `glass-selected`. սահող ներդիրի ֆոն՝ `tab-glider`
  (տես «Իմ անկյունը»)։ Ներդիր փոխելիս էջի տվյալները նորից չբեռնել (`shouldRevalidate`)։
- «Ավելի քիչ թափանցիկություն» և «Քիչ շարժում» ռեժիմներում ապակին անթափանց է։
- **Կենդանի բեկում ՉԴՆԵԼ** (SVG `feDisplacementMap` `backdrop-filter`-ում)։ Փորձվեց 2026-11-21 (#215). Chrome-ը այն
  հաշվում է պրոցեսորով ամեն կադր, հեռախոսում մենյուն ու պատուհանները կտրտվում էին։ Ապակու տեսքը՝ միայն
  box-shadow-ով (`--lg-thick`՝ հաստ եզրի լույս)։
- Թեման փոխելը՝ միայն `applyThemePreference`-ով (`theme.ts`). տարրերի `transition`-ները անջատված են
  (`html[data-theme-switching]`), իսկ էկրանը սահուն է անցնում View Transition-ով (`animate: true`, 420 մվ)։
  Մենյուի blur-ը չանջատել. մեկ կադր թափանցիկ թարթում էր (2026-11-21)։

## 3. Դաշտեր և որոնում

- **Էջերի որոնումը՝ միայն անկյունի կոճակից** (`ExpandingSearch`, `app/components/page-layout.tsx`).
  կլոր կոճակը սահուն երկարում է և դառնում pill դաշտ (`header-search`), X-ով կամ Esc-ով՝ հետ։
  Վերնագրի տակ առանձին որոնման դաշտ չդնել։ Բացառություն՝ գլխավոր էջը (այնտեղ մեծ դաշտ է)։
  `PageHeader`-ին՝ `search={{ open, onOpen, field }}` էջի սեփական որոնման համար, առանց դրա՝ «Փնտրել այս էջում»։

- Որոնման դաշտ՝ `search-field` (բոլոր էջերում նույնը)։ Ձախում՝ պատկերակ, աջում՝ ոսկեգույն
  կլոր `search-go` կոճակ, որը երևում է միայն տեքստ գրելուց հետո։ Input-ին՝ `enterKeyHint="search"`։
- Մնացած դաշտերը՝ `fieldControl` / `formLayout`։ Եզրը միշտ `--field-border` է (կոնտրաստը
  ֆոնի նկատմամբ ≥ 3:1, WCAG 1.4.11)։ Մութ թեմայում դաշտը ֆոնից **բաց** է, ոչ թե մութ։

## 4. Կոճակների խմբեր

- Ընտրության խումբ (segmented)՝ `frosted-card p-1.5` + ներսում `rounded-button` կոճակներ.
  ընտրվածը՝ `bg-[rgb(217_181_111/18%)]` և ոսկեգույն ներքին եզր։
- «Կարդացել եմ» (`read-mark`)՝ նույն ապակով, `rounded-card`։
- Նյութի գործողություններ՝ `action-bar` (մեկ ապակե գոտի, ներսում թափանցիկ `action-tile`)։
  Հերթականություն՝ Պահել · Հիշեցնել · Կիսվել։ Telegram-ի կոճակ չդնել (կայքը առաջնային է)։
- Մենյուի սալիկներ՝ պատկերակ վերևում, անունը տակը, մեկ բառ (մինչև ~14 տառ)։

## 5. Գույն և տեքստ

- Ոսկեգույն՝ `text-gold` / `text-gold-bright` (պատկերակներ, ակտիվ վիճակ), հիմնական տեքստ՝
  `text-ink`, երկրորդական՝ `text-muted`, նշումներ՝ `text-faint` (միայն ոչ կարևոր տեքստի համար)։
- Գլխավոր գործողություն՝ ոսկեգույն գրադիենտ `linear-gradient(135deg,#e2c27e,#b07d2e)`, տեքստը `#2a1708`։
- Գլխատառերով փոքր վերնագրեր՝ `text-[11px] font-bold tracking-[1.2px] text-gold uppercase`։

## 6. Որոնում. «Գուցե նկատի ունեիք»

`shared/search-correction.ts`. լատինատառը դառնում է հայերեն, տառասխալը ուղղվում է ըստ
վերնագրերի բառերի։ Լատինատառ կամ ոչինչ չգտած որոնումը բացվում է ուղղվածով (`?asked=`՝
մարդու գրածը, «Փնտրել հենց …» հղումով, `?exact=1`)։ Մնացածում՝ «Գուցե նկատի ունեիք» և
«Նման բառեր» կոճակներ։
